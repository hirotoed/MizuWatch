# MizuWatch

MizuWatchは、河川・湖・ため池などの水域を低コストで観測する
水上環境観測システムです。

## 目的

- 水温や気象データの取得
- GPSによる観測地点の記録
- LTE-Mによるリアルタイム送信
- 通信圏外ではSDカードへ保存
- 観測データをWeb地図上で確認
- 機械学習による異常地点の検出

## 現在の開発状況

- Raspberry Pi Pico Wによる試作機を作成済み
- GPS、温湿度、気圧、水温センサーを使用
- Google Apps Scriptへのデータ送信を検証済み
- 次期基板をKiCadで設計予定

## 主な実証場所

河川・ため池

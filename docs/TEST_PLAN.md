# MizuWatch 実証実験計画

## 目的

MizuWatchが実際の水域で安定して観測できるか評価する。

## 実証場所

久留米市周辺の河川・ため池などを想定。

## 評価項目

### センサー

- 水温測定精度
- 気温測定精度
- GPS取得精度

### 通信

- LTE-M送信成功率
- 通信圏外時のSD保存
- 通信復旧後の自動再送

### 電源

- 連続稼働時間
- 消費電力

### 防水

- 浸水の有無
- 長時間運用時の安定性

## 記録するもの

- 実験日時
- 実験場所
- 天候
- 稼働時間
- 送信成功率
- GPS精度
- センサーデータ
- 発生した問題
